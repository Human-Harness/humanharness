# Human Harness — Plan 4a: Harness authoring (guide and CLI)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A developer creates a harness in the terminal: `humanharness init` makes a repo from a minimal template that runs as is and installs the `/new-harness` guide (Claude Code skill and Codex `AGENTS.md` section, from one source); the guide asks one question at a time, records each decision in `HARNESS.md` and writes the code; `humanharness check` validates the result deterministically; `humanharness run` drives one task against a real engine with the app's own task logic and prints a usage report; `humanharness dev` checks, then opens the app with the harness.

**Architecture:** A new workspace package `@humanharness/cli` (bin `humanharness`) holds the commands, the template (`packages/cli/template/`), the guide source (`packages/cli/guide/new-harness.md`) and two re-export entry points a harness repo imports (`@humanharness/cli/sdk`, `@humanharness/cli/ui`), so a harness repo depends on the CLI only. `TaskManager`, `TurnController` and the other task modules of the shell have no Electron dependency, so nothing is extracted: the shell exposes them through a barrel (`@humanharness/shell/tasks`) and moves its command runner to a shared `command-deps.ts`; `TaskManager` gains a public `finish()` for the terminal's `q`. The shell's Vite config learns three development-only switches (`HH_DEV_ENGINE`, `HH_OUT_DIR`, and serving a harness folder that lives outside the repository). `run` replaces the root `hh-dev` script and `packages/runtime/src/dev.ts`.

**Tech Stack:** unchanged (Node ≥ 22, TypeScript 7, pnpm 12 via corepack, Vitest 5, Electron 44 + electron-vite 5, React 19, zod 4, Playwright 1.63.0). The CLI runs TypeScript source through `tsx` (`tsx/esm/api` `register()`), already in the workspace.

Spec: `docs/superpowers/specs/2026-10-12-harness-authoring-design.md` (source of truth; section numbers below refer to it). Previous plan: `docs/superpowers/plans/2026-10-12-03c-resources.md`.

## Conventions

- Same as plans 1–3c: English everywhere (code, docs, comments, CLI output, `HARNESS.md`, the guide); a harness's UI strings stay in `locales/{es,en}.json`. Packages export TS source; extensionless imports; tests in `packages/<name>/test/`; `corepack pnpm …` (pnpm is not on PATH); one commit per task, ending with the session trailers from your system reminder.
- Every task ends with `corepack pnpm typecheck` and `corepack pnpm test` green before its commit, run from the repository root. Tasks that touch the shell's main process or its Vite config also run `corepack pnpm app:build`. Task 17 runs `corepack pnpm e2e`.
- Tests that need a harness repo create one with `initHarness({ …, install: false })` in a folder under `os.tmpdir()` (never inside the repository: Vitest would pick up files there, and the repository's own `pnpm-workspace.yaml` would claim it).
- **Compliance (core spec §5), restated for this plan:** the CLI never reads `~/.claude`, `~/.codex` or `~/.gemini`; it never passes, injects or strips credential or auth environment variables (child processes get the parent's environment unchanged, minus `ELECTRON_RUN_AS_NODE` where the app's own e2e helper already drops it); the official CLIs run unmodified. `run` checks an engine only through its official CLI (`detectEngine`), exactly as the app does. The guide repeats these rules to the agent that follows it.

## Decisions this plan takes where the spec leaves room

- **Cost names.** The spec writes `cost: "low"`/`"high"`; the manifest schema's values are `light`, `medium`, `heavy` (`ACTION_COSTS`). The template uses `cost: "light"`; the `tier-cost` warning fires for `heavy` on a `light` action and for `light` on a `deep` one.
- **Block name.** Block names allow no dash (`/^[a-z][a-z0-9_]*$/`), so the template's block is `example_card` (tool `show_example_card`).
- **No extraction.** `task-manager.ts`, `turn-controller.ts`, `task-store.ts`, `task-prompts.ts`, `models.ts`, `usage-log.ts`, `chat-log.ts`, `engine-status.ts`, `engine-command.ts`, `shared-config.ts` and `references.ts` import nothing from Electron (only Node, workspace packages and the type-only `@humanharness/ui/client`). The shell adds `"exports": { "./tasks": …, "./package.json": … }` and a barrel; the CLI depends on `@humanharness/shell` (the spec already lists it, for `dev`). The command runner the app builds in `index.ts` moves to `command-deps.ts` (`createCommandDeps(nodePath)`), so `run` resolves the bundled Codex adapter from the shell exactly as the app does. The app's behavior does not change.
- **`q` closes the task.** `TaskManager` gets a public `finish()`: the closing turn (`save_note`) of the open task, starting nothing after it. The app does not call it.
- **What a harness repo imports.** `@humanharness/cli/sdk` (everything from `@humanharness/harness-sdk`, which now also re-exports `z`, so a manifest's schemas and the SDK's `instanceof z.ZodObject` check share one zod) and `@humanharness/cli/ui` (everything from `@humanharness/ui`, plus `useTranslation`). React, react-dom, i18next and react-i18next are deduped to the shell's copies in the renderer build, and the dev server may serve the harness folder, so a harness outside this repository builds without its own React.
- **Template id.** The template is written with the id `example-harness`; `init` replaces that string in every template file. The name starts as the id (spec §4). `author` starts as `"Your name"`; the guide's Identity phase sets it.
- **`init --skip-install`** (the spec's "flag for tests"): skips `corepack pnpm install` and `git init` but creates `node_modules/@humanharness/cli` as a symlink to `<core>/packages/cli`, which is what pnpm makes of the `link:` dependency, so `check` and `run` work right after it. `init` copies the core's `packageManager` field so `corepack pnpm install` uses the same pnpm.
- **`--harness <dir>`** on `check`, `run` and `dev` (default: the current folder), plus a root script `humanharness`, so the demo can still be run from the repository root now that `hh-dev` is gone: `corepack pnpm humanharness run manifest --harness harnesses/demo`.
- **`run` defaults.** Engine: the harness's first available engine. Language: `en` when the harness offers it, else its first language. Work folder: `--folder`, else a new `hh-run-<id>-*` folder under the OS temp dir, printed and kept. Local history: under `<os temp>/humanharness-run-history/`. `run` does not require the app's legal notice (that gate lives in the app's shared config and is part of the app's onboarding); the engine must be installed, current and signed in, or `run` stops with the app's own English message (`errors.*` in `@humanharness/i18n`).
- **Report.** Phases are `run` (the task's first turn), `follow-up` (later turns of the same task), `checkpoint` and `close`. "Used about N tokens" is input + output over every phase; cache reads and writes are shown per phase but not added. Peak context comes from the task view's `context.used`, as the app's meter does.
- **`check` details.** `harness-md-mismatch` compares action ids and tiers, the `(questions)` row (required) with `questions.tier`, the three permission lines and the `engines:` line. The `i18n` rule checks that every declared language has `locales/<lang>.json` (or the manifest's `locales` folder), that all have the same keys, and that every `t("key")` in `ui/` exists in each; a label or description without both languages is already a `schema` error (`localizedText` requires `es` and `en`). The pillar rules read the briefs and `agent/AGENTS.md` (the instructions file), because the demo asks for `show_choices` there. `checkHarness` takes a `mode` (`development` default); the CLI always checks in development, and plan 4b passes `distribution`.
- **Brand list.** `brandNames()` in `engines` is each engine's name, the first word of its provider and per-engine extra marks (`ChatGPT`, `GPT` for Codex): Claude, Anthropic, Codex, OpenAI, ChatGPT, GPT, Kimi, Moonshot, Gemini, Google, Qwen, Alibaba. Matching is case-insensitive on word boundaries.
- **`dev --engine`** sets `HH_DEV_ENGINE`; the app reads it in development builds only and saves it as the engine when its config has none yet. **`dev --build <dir>`** builds into `<dir>` (through `HH_OUT_DIR`) instead of opening the app; the end-to-end test uses it.
- **Removed with `dev.ts`:** `packages/runtime/src/session-store.ts` and its test (`dev.ts` was its only user). Dated plans and spikes that mention `hh-dev` stay as they are (they are history); `README.md` is updated.
- **The template has no tests of its own** and ships a `tsconfig.json` for editors. The root `tsconfig.json` typechecks it in place through two `paths` entries.

```ts
import { execFile } from "node:child_process";
import { constants, promises as fs } from "node:fs";
import { createRequire } from "node:module";
import os from "node:os";
import type { CommandDeps } from "./engine-command";

const requireFromHere = createRequire(import.meta.url);

/**
 * How the app (and `humanharness run`) runs engine CLIs. `nodePath` runs the bundled adapters: Electron as
 * Node in the app, Node itself in the CLI. Modules resolve from the shell, where the adapters are dependencies.
 */
export function createCommandDeps(nodePath: string): CommandDeps {
  return {
    shell: process.env.SHELL || "/bin/zsh",
    home: os.homedir(),
    run: (cmd, args, env) =>
      new Promise((resolve) => {
        execFile(cmd, args, { timeout: 10_000, env: { ...process.env, ...env } }, (err, stdout) => {
          const e = err as (Error & { code?: unknown; killed?: boolean }) | null;
          const code = e ? (typeof e.code === "number" ? e.code : 1) : 0;
          resolve({
            stdout: String(stdout),
            code,
            // Killed by the timeout, or never started (e.g. ENOENT): no real answer.
            ...(e?.killed ? { timedOut: true } : {}),
            ...(e && typeof e.code === "string" ? { spawnError: true } : {}),
          });
        });
      }),
    isExecutable: (file) => fs.access(file, constants.X_OK).then(() => true, () => false),
    electronPath: nodePath,
    resolveModule: (id, from) => (from ? createRequire(from) : requireFromHere).resolve(id),
  };
}
```

/**
 * `humanharness dev --engine <id>` (HH_DEV_ENGINE): the engine a fresh app starts with. Development builds
 * only, and only an engine this harness offers; anything else is ignored.

export function devEngine(env: Record<string, string | undefined>, packaged: boolean, offered: string[]): string | undefined {
  if (packaged) return undefined;
  const id = env.HH_DEV_ENGINE;
  return id && offered.includes(id) ? id : undefined;
}

import fs from "node:fs";
import os from "node:os";
import path from "node:path";
import { PassThrough, Writable } from "node:stream";
import { fileURLToPath } from "node:url";
import type { Io } from "../src/cli";

/** The repository: what `--core` points at in tests. */
export const CORE = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "../../..");

/** A writable that keeps what was written. */
export function memoryStream(): { stream: Writable; text: () => string } {
  let text = "";
  const stream = new Writable({
    write(chunk, _encoding, callback) {
      text += String(chunk);
      callback();
    },
  });
  return { stream, text: () => text };
}

/** An Io over memory: `input` is what the person types (already ended). */
export function memoryIo(cwd: string, input = "") {
  const out = memoryStream();
  const err = memoryStream();
  const stdin = new PassThrough();
  stdin.end(input);
  const io: Io = { cwd, stdin, stdout: out.stream, stderr: err.stream };
  return { io, out: out.text, err: err.text };
}

/** A temporary folder outside the repository, removed by `cleanup`. */
export function tempRoot(prefix: string): { root: string; cleanup: () => void } {
  const root = fs.mkdtempSync(path.join(os.tmpdir(), prefix));
  return { root, cleanup: () => fs.rmSync(root, { recursive: true, force: true }) };
}

export const read = (dir: string, file: string) => fs.readFileSync(path.join(dir, file), "utf8");

/** Replaces `from` with `to` in a file of a harness repo; fails when `from` isn't there. */
export function replaceIn(dir: string, file: string, from: string, to: string): void {
  const text = read(dir, file);
  if (!text.includes(from)) throw new Error(`${file} has no ${JSON.stringify(from)}`);
  fs.writeFileSync(path.join(dir, file), text.replace(from, to));
}

import type { Readable, Writable } from "node:stream";
import { type ParseArgsConfig, parseArgs } from "node:util";

/** Where a command reads and writes: the process in the bin, memory in tests. */
export interface Io {
  cwd: string;
  stdin: Readable;
  stdout: Writable;
  stderr: Writable;
}

/** A wrong command line: the message is printed and the exit code is 2. */
export class UsageError extends Error {}

/** A clear stop (a harness with errors, an engine that isn't ready): the message is printed and the exit code is 1. */
export class CliError extends Error {}

/** `parseArgs` with positionals, where an unknown option is a UsageError. */
export function parseCommand<O extends NonNullable<ParseArgsConfig["options"]>>(args: string[], options: O) {
  try {
    return parseArgs({ args, options, allowPositionals: true, strict: true });
  } catch (err) {
    throw new UsageError(err instanceof Error ? err.message : String(err));
  }
}

`packages/cli/src/main.ts`:

```ts
import { CliError, type Io, UsageError } from "./cli";

type Command = (args: string[], io: Io) => Promise<number>;

export const USAGE = [
  "Usage: humanharness <command>",
  "",
  "Commands:",
  "  init <dir> [--core <path>] [--id <id>]   Create a harness repo from the template and install the guide",
  "  check [--json]                           Validate the harness in the current folder",
  "  run <action> [--engine claude|codex] [--tier light|standard|deep] [--folder <dir>] [--language es|en]",
  "                                           Run one task against a real engine in the terminal",
  "  dev [--engine <id>]                      Check the harness, then open the app with it",
  "",
  "check, run and dev take --harness <dir> to work on another folder than the current one.",
  "",
].join("\n");

/** The commands, by name. Each later task adds its own. */
const COMMANDS: Record<string, Command> = {};

export async function main(argv: string[], io: Io): Promise<number> {
  const [name, ...args] = argv;
  if (name === undefined || name === "help" || name === "--help" || name === "-h") {
    io.stdout.write(USAGE);
    return 0;
  }
  const command = Object.hasOwn(COMMANDS, name) ? COMMANDS[name] : undefined;
  if (!command) {
    io.stderr.write(`Unknown command: ${name}\n\n${USAGE}`);
    return 2;
  }
  try {
    return await command(args, io);
  } catch (err) {
    if (err instanceof UsageError) {
      io.stderr.write(`${err.message}\n`);
      return 2;
    }
    if (err instanceof CliError) {
      io.stderr.write(`${err.message}\n`);
      return 1;
    }
    throw err;
  }
}

/** The sections of a harness's HARNESS.md, in order (spec §6). */
export const HARNESS_SECTIONS = ["Task", "Decisions", "Flow", "Context", "Models", "Permissions and engines", "Identity", "Open questions", "Decision log"] as const;
export type HarnessSection = (typeof HARNESS_SECTIONS)[number];

/** The Flow table's row for free questions. */
export const QUESTIONS_ROW = "(questions)";
export const PERMISSION_KEYS = ["edit", "exec", "web"] as const;
export type PermissionKey = (typeof PERMISSION_KEYS)[number];

export interface Section {
  title: string;
  /** 1-based line of the `## ` heading. */
  line: number;
  lines: { text: string; line: number }[];
}

export interface FlowRow {
  action: string;
  tier: string;
  cost: string;
  purpose: string;
  line: number;
}

export interface PermissionLine {
  key: PermissionKey;
  value: string;
  /** The text after the dash; empty when there is none. */
  reason: string;
  line: number;
}

export interface HarnessDoc {
  /** By heading; the first of two equal headings wins. */
  sections: Map<string, Section>;
  /** The Flow table, or null when the Flow section has no `| Action | Tier | Cost | Purpose |` table. */
  flow: FlowRow[] | null;
  permissions: PermissionLine[];
  engines: { ids: string[]; line: number } | null;
}

const HEADING = /^##\s+(.+?)\s*$/;
const FLOW_HEADER = /^\|?\s*Action\s*\|\s*Tier\s*\|\s*Cost\s*\|\s*Purpose\s*\|?\s*$/i;
const SEPARATOR = /^\|?\s*:?-{3,}:?\s*(\|\s*:?-{3,}:?\s*)*\|?\s*$/;
/** `- edit: none — reason` (also `exec`, `web`; backticks, quotes, `—`, `–`, `--` or `-` before the reason). */
const PERMISSION = /^\s*(?:[-*]\s+)?`?(edit|exec|web)`?\s*:\s*`?"?([A-Za-z]+)"?`?\s*(?:(?:—|–|--|-)\s*(.*?))?\s*$/i;
const ENGINES_LINE = /^\s*(?:[-*]\s+)?`?engines`?\s*:\s*(.+?)\s*$/i;

const cells = (row: string) =>
  row
    .trim()
    .replace(/^\|/, "")
    .replace(/\|$/, "")
    .split("|")
    .map((c) => c.trim().replace(/^`(.*)`$/, "$1"));

export function parseHarnessMd(text: string): HarnessDoc {
  const sections = new Map<string, Section>();
  const lines = text.split(/\r?\n/);
  let current: Section | null = null;
  for (let i = 0; i < lines.length; i++) {
    const heading = HEADING.exec(lines[i]);
    if (heading) {
      current = { title: heading[1], line: i + 1, lines: [] };
      if (!sections.has(heading[1])) sections.set(heading[1], current);
    } else current?.lines.push({ text: lines[i], line: i + 1 });
  }
  return { sections, flow: parseFlow(sections.get("Flow")), ...parsePermissions(sections.get("Permissions and engines")) };
}

/** A section's text without HTML comments, trimmed: "" means the section is empty. */
export function sectionText(section: Section | undefined): string {
  if (!section) return "";
  return section.lines
    .map((l) => l.text)
    .join("\n")
    .replace(/<!--[\s\S]*?-->/g, "")
    .trim();
}

function parseFlow(section: Section | undefined): FlowRow[] | null {
  if (!section) return null;
  const header = section.lines.findIndex((l) => FLOW_HEADER.test(l.text));
  if (header < 0 || !SEPARATOR.test(section.lines[header + 1]?.text ?? "")) return null;
  const rows: FlowRow[] = [];
  for (const l of section.lines.slice(header + 2)) {
    if (!l.text.trim().startsWith("|")) break;
    const [action = "", tier = "", cost = "", purpose = ""] = cells(l.text);
    rows.push({ action, tier: tier.toLowerCase(), cost: cost.toLowerCase(), purpose, line: l.line });
  }
  return rows;
}

function parsePermissions(section: Section | undefined): Pick<HarnessDoc, "permissions" | "engines"> {
  const permissions: PermissionLine[] = [];
  let engines: HarnessDoc["engines"] = null;
  for (const l of section?.lines ?? []) {
    const p = PERMISSION.exec(l.text);
    if (p) {
      const key = p[1].toLowerCase() as PermissionKey;
      if (!permissions.some((x) => x.key === key)) permissions.push({ key, value: p[2].toLowerCase(), reason: p[3] ?? "", line: l.line });
      continue;
    }
    const e = ENGINES_LINE.exec(l.text);
    if (e && !engines) {
      const ids = e[1].split(/[,\s]+/).map((x) => x.replace(/`/g, "").toLowerCase()).filter(Boolean);
      engines = { ids, line: l.line };
    }
  }
  return { permissions, engines };
}
```

# /new-harness: build this harness step by step

You are helping a developer turn this repository into a Human Harness harness: a desktop app that puts a purpose-built interface and workflow on top of the person's own AI subscription. A good harness gets three pillars right:

1. **A decision UI.** The person decides through choices and cards, not by typing into a chat.
2. **An agentic flow** that keeps the AI on course: tasks with briefs, a guided path, choices that lead somewhere.
3. **Context and model management.** Each task saves what matters as a note, runs on the smallest model that does the job and gets only the permissions it needs.

## How to work

- Ask **one question at a time**, in the developer's language. Write every file in English; the harness's UI strings stay in Spanish and English in `locales/`.
- Read `HARNESS.md` first: it is this harness's living decision log. Never ask again what it already answers; offer to revisit it instead.
- Each phase ends with two things done together: its `HARNESS.md` section updated, and the code changed to match. Add a dated entry to **Decision log** for each decision: the decision, the reason, the alternatives rejected.
- After each phase, suggest running `corepack pnpm check` (it runs `humanharness check`), and fix every error it reports.
- When the developer is unsure, write the question under **Open questions** and move on.

## Where things are

- The core checkout is the folder `package.json` links to: `"@humanharness/cli": "link:<core>/packages/cli"`. Below, `<core>` is that folder.
- `<core>/harnesses/demo` is a complete example (custom blocks, a guided path, briefs, references). Read it for ideas; never copy it as a starting point.
- `<core>/docs/architecture/` explains how the core works: `manifest.md`, `blocks.md`, `context.md`, `turn.md`, `engines.md`, `authoring.md`.
- In this repository: `harness.config.ts` (the manifest), `agent/AGENTS.md` (the instructions to the AI), `agent/tasks/*.md` (one brief per action), `ui/` (the screen and the block components), `locales/es.json` and `locales/en.json` (the UI strings).
- Import the SDK from `@humanharness/cli/sdk` (`defineHarness`, `defineBlock`, `z`) and the UI kit from `@humanharness/cli/ui` (`HarnessApp`, `BlockProps`, `useTranslation`).

- Never edit files outside this repository.
- Never read `~/.claude`, `~/.codex` or `~/.gemini`, and never touch credentials or their environment variables. People sign in through the engine's official CLI; a harness never handles accounts.

## Phase 1 — Task

Fills: HARNESS.md → Task

Ask what job the person gets done with this harness, and for whom. Insist on a concrete outcome ("a weekly meal plan with its shopping list", "a reviewed pull request"). If the answer is "a chat about X", ask what the person has in hand when they are done.

Write two or three sentences: who, the outcome, and what makes it hard without the harness.

## Phase 2 — Decisions

Fills: HARNESS.md → Decisions

Ask which choices the person makes along the way, and what they need to see in order to decide. For each one:

- When picking among up to four ways to continue is enough, it is the core `choices` block (`show_choices`).

Keep schemas small and bounded (maximum lengths, maximum items). A state-only block (`visible: false`) updates a side panel instead.

Replace the template's `example_card` block once the harness has its own.

## Phase 3 — Flow

Fills: HARNESS.md → Flow

Ask which tasks (actions) exist. For each one: an id, a label and a one-line description in Spanish and English, a brief in `agent/tasks/<id>.md`, and a cost hint (`light`, `medium` or `heavy`: how much of the person's plan it tends to use).

- `light` for mechanical or short work;

- `edit`: `folder` (the AI may change files in the person's folder) or `none`;

Fills: HARNESS.md → Identity

## Phase 8 — Verify

Fills: HARNESS.md → Open questions, Decision log

1. Run `corepack pnpm check` and fix every error.
2. Go through the warnings with the developer: fix each one, or record in the Decision log why it stays.
3. Run at least one task for real: `corepack pnpm run run <action> --engine claude` (or `codex`); the engine's official CLI must be signed in. Read its report (tokens per phase, peak context against the cap, the cost hint) and adjust tiers or briefs.

5. Leave **Open questions** empty, or with only what the developer chose to keep open.

export interface InitOptions {
  dir: string;
  /** The core checkout to link to. Default: the one this CLI runs from. */
  core?: string;
  id?: string;
  /** false: no `pnpm install` and no `git init`; the CLI is linked directly (tests). */
  install?: boolean;

const exists = (p: string) => fs.access(p).then(() => true, () => false);

/** A harness id from a folder name: lowercase, anything else becomes a dash. */
export function idFromFolder(dir: string): string {
  return path
    .basename(path.resolve(dir))
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-+|-+$/g, "");
}

export async function initHarness(o: InitOptions): Promise<{ dir: string; id: string; core: string }> {
  const dir = path.resolve(o.dir);
  const id = o.id ?? idFromFolder(dir);
  if (!HARNESS_ID.test(id)) {
    throw new UsageError(`"${id}" is not a valid harness id: use lowercase letters, digits and dashes, starting with a letter (or pass --id).`);
  }
  const core = path.resolve(o.core ?? CORE_DIR);
  const cliDir = cliDirOf(core);
  if (!(await exists(path.join(cliDir, "package.json")))) throw new UsageError(`${core} is not a Human Harness checkout (it has no packages/cli).`);
  const entries = await fs.readdir(dir).catch((err: NodeJS.ErrnoException) => {
    if (err.code === "ENOENT") return [];
    throw err;
  });
  if (entries.length > 0) throw new UsageError(`${dir} is not empty.`);

  await fs.mkdir(dir, { recursive: true });
  await copyTemplate(templateDirOf(core), dir, id);
  const date = (o.today ?? new Date()).toISOString().slice(0, 10);
  await fs.appendFile(
    path.join(dir, "HARNESS.md"),
    `\n- ${date} — Created from the Human Harness template with \`humanharness init\`. Reason: start from a harness that runs. Alternatives rejected: copying the demo, which is a reference, not a starting point.\n`,
  );
  await fs.writeFile(path.join(dir, "package.json"), `${JSON.stringify(await packageJson(dir, id, core), null, 2)}\n`);
  await fs.writeFile(path.join(dir, ".gitignore"), "node_modules/\n");
  const guide = await readGuide(guideFileOf(core));
  await fs.mkdir(path.join(dir, ".claude", "skills", "new-harness"), { recursive: true });
  await fs.writeFile(path.join(dir, ".claude", "skills", "new-harness", "SKILL.md"), skillFile(guide));
  await fs.writeFile(path.join(dir, "AGENTS.md"), agentsFile(id, guide));

  if (o.install === false) await linkCli(dir, cliDir);
  else {
    await runIn(dir, "corepack", ["pnpm", "install"]);
    await runIn(dir, "git", ["init"]);
  }
  const log = o.log ?? (() => {});
  log(`Created ${id} in ${dir}.`);
  log("Next: open Claude Code or Codex in that folder and run /new-harness.");
  log("Check it at any time with: corepack pnpm check");
  return { dir, id, core };
}

/** Copies the template, replacing the template's id with `id` in every file (all of them are text). */
async function copyTemplate(from: string, to: string, id: string): Promise<void> {
  for (const entry of await fs.readdir(from, { withFileTypes: true })) {
    const source = path.join(from, entry.name);
    const target = path.join(to, entry.name);
    if (entry.isDirectory()) {
      await fs.mkdir(target, { recursive: true });
      await copyTemplate(source, target, id);
    } else if (entry.isFile()) {
      await fs.writeFile(target, (await fs.readFile(source, "utf8")).replaceAll(TEMPLATE_ID, id));
    }
  }
}

async function packageJson(dir: string, id: string, core: string) {
  const rel = path.relative(dir, cliDirOf(core));
  const link = path.isAbsolute(rel) ? cliDirOf(core) : rel.split(path.sep).join("/");
  const corePkg = JSON.parse(await fs.readFile(path.join(core, "package.json"), "utf8")) as { packageManager?: string };
  return {
    name: id,
    version: "0.1.0",
    private: true,
    type: "module",
    ...(corePkg.packageManager ? { packageManager: corePkg.packageManager } : {}),
    scripts: { check: "humanharness check", run: "humanharness run", dev: "humanharness dev" },
    dependencies: { "@humanharness/cli": `link:${link}` },
  };
}

/** What `pnpm install` makes of the `link:` dependency: node_modules/@humanharness/cli → <core>/packages/cli. */
async function linkCli(dir: string, cliDir: string): Promise<void> {
  const scope = path.join(dir, "node_modules", "@humanharness");
  await fs.mkdir(scope, { recursive: true });
  await fs.symlink(cliDir, path.join(scope, "cli"), "dir");
}

function runIn(cwd: string, command: string, args: string[]): Promise<void> {
  return new Promise((resolve, reject) => {
    const child = spawn(command, args, { cwd, stdio: "inherit" });
    child.on("error", reject);
    child.on("exit", (code) => (code === 0 ? resolve() : reject(new Error(`${command} ${args.join(" ")} exited with ${code}`))));
  });
}

export async function initCommand(args: string[], io: Io): Promise<number> {
  const { values, positionals } = parseCommand(args, { core: { type: "string" }, id: { type: "string" }, "skip-install": { type: "boolean" } });
  if (positionals.length !== 1) throw new UsageError("Usage: humanharness init <dir> [--core <path>] [--id <id>]");
  await initHarness({
    dir: path.resolve(io.cwd, positionals[0]),
    ...(values.core ? { core: path.resolve(io.cwd, values.core) } : {}),
    ...(values.id ? { id: values.id } : {}),
    install: values["skip-install"] !== true,
    log: (line) => io.stdout.write(`${line}\n`),
  });
  return 0;
}

const error = finding("error");

/** Validates the harness in `dir` (spec §7). Errors make the CLI exit with 1. */
export async function checkHarness(dir: string, opts: { mode?: Mode } = {}): Promise<CheckResult> {
  const root = path.resolve(dir);
  const findings: Finding[] = [];
  const harness = await loadManifest(root, findings);
  const mdText = await read(path.join(root, HARNESS_MD));
  const doc = mdText === null ? null : parseHarnessMd(mdText);
  if (!doc) findings.push(error("harness-md-missing", "HARNESS.md is missing: create it with `humanharness init` or the /new-harness guide.", HARNESS_MD));
  else if (!doc.flow) findings.push(error("harness-md-missing", "HARNESS.md has no Flow table (| Action | Tier | Cost | Purpose |) under ## Flow.", HARNESS_MD, doc.sections.get("Flow")?.line));
  if (!harness) return { findings, harness: null };

  const briefs = await readBriefs(harness);
  findings.push(...briefFindings(harness, briefs));
  findings.push(...(await i18nFindings(harness)));
  findings.push(...brandFindings(harness));
  findings.push(...engineFindings(harness, opts.mode ?? "development"));
  if (doc?.flow) findings.push(...mismatchFindings(harness, doc));
  return { findings, harness };
}

async function loadManifest(root: string, findings: Finding[]): Promise<LoadedHarness | null> {
  const file = path.join(root, MANIFEST);
  if (!(await exists(file))) {
    findings.push(error("schema", "harness.config.ts is missing.", MANIFEST));
    return null;
  }
  try {
    return await loadHarness(file);
  } catch (err) {
    const issues = (err as { issues?: { path: PropertyKey[]; message: string }[] }).issues;
    if (Array.isArray(issues)) {
      for (const issue of issues) findings.push(error("schema", `${issue.path.map(String).join(".") || "(manifest)"}: ${issue.message}`, MANIFEST));
    } else findings.push(error("schema", err instanceof Error ? err.message : String(err), MANIFEST));
    return null;
  }
}

/** Each action's brief text; null when it can't be read. */
async function readBriefs(h: LoadedHarness): Promise<Map<string, string | null>> {
  const briefs = new Map<string, string | null>();
  for (const [id, action] of Object.entries(h.actions)) briefs.set(id, await read(resolveInHarness(h, action.prompt)));
  return briefs;
}

function briefFindings(h: LoadedHarness, briefs: Map<string, string | null>): Finding[] {
  return Object.entries(h.actions).flatMap(([id, action]) => {
    const text = briefs.get(id);
    if (text === null || text === undefined) return [error("brief-missing", `Action "${id}": its brief ${action.prompt} does not exist.`, MANIFEST)];
    if (!text.trim()) return [error("brief-missing", `Action "${id}": its brief ${action.prompt} is empty.`, path.relative(h.root, resolveInHarness(h, action.prompt)))];
    return [];
  });
}

/** Every key of a locale file, nested keys joined with dots. */
export function flatKeys(o: Record<string, unknown>, prefix = ""): string[] {
  return Object.entries(o).flatMap(([k, v]) =>
    typeof v === "object" && v !== null && !Array.isArray(v) ? flatKeys(v as Record<string, unknown>, `${prefix}${k}.`) : [`${prefix}${k}`],
  );
}

  const localesDir = h.locales ?? "locales";
  const uiFiles = await sourceFiles(path.join(h.root, "ui"));
  if (!(await exists(resolveInHarness(h, localesDir))) && uiFiles.length === 0) return out;
  const keys = new Map<string, Set<string>>();
  for (const lang of h.languages) {
    const file = path.join(localesDir, `${lang}.json`);
    const text = await read(resolveInHarness(h, file));
    if (text === null) {
      out.push(error("i18n", `${file} is missing: every declared language needs its strings.`, file));
      continue;
    }
    try {
      keys.set(lang, new Set(flatKeys(JSON.parse(text) as Record<string, unknown>)));
    } catch {
      out.push(error("i18n", `${file} is not valid JSON.`, file));
    }
  }
  const all = [...new Set([...keys.values()].flatMap((s) => [...s]))];
  for (const [lang, set] of keys) {
    for (const key of all) if (!set.has(key)) out.push(error("i18n", `"${key}" is missing in ${lang}.`, path.join(localesDir, `${lang}.json`)));
  }
  for (const file of uiFiles) {
    const text = await fs.readFile(file, "utf8");
    for (const m of text.matchAll(UI_KEY)) {
      const line = text.slice(0, m.index).split("\n").length;
      for (const [lang, set] of keys) {
        if (!set.has(m[1])) out.push(error("i18n", `"${m[1]}" is used here but missing in ${lang}.`, path.relative(h.root, file), line));
      }
    }
  }
  return out;
}

const escapeRegExp = (s: string) => s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");

/** The first provider or model brand in `text` (whole words, any case), or null. */
export function findBrand(text: string): string | null {
  for (const brand of brandNames()) {
    if (new RegExp(`(?<![A-Za-z0-9])${escapeRegExp(brand)}(?![A-Za-z0-9])`, "i").test(text)) return brand;
  }
  return null;
}

function engineFindings(h: LoadedHarness, mode: Mode): Finding[] {

function mismatchFindings(h: LoadedHarness, doc: HarnessDoc): Finding[] {

    if (!Object.hasOwn(h.actions, row.action)) mismatch(`The Flow table lists "${row.action}", which harness.config.ts doesn't declare.`, row.line);

  else if (questions.tier !== questionsTier) mismatch(`${QUESTIONS_ROW}: the Flow table says tier ${questions.tier}, harness.config.ts says ${questionsTier}.`, questions.line);

  const permsLine = doc.sections.get("Permissions and engines")?.line;

    const p = doc.permissions.find((x) => x.key === key);

    else if (p.value !== manifest[key]) mismatch(`${key}: HARNESS.md says ${p.value}, harness.config.ts says ${manifest[key]}.`, p.line);

  if (!doc.engines) mismatch('Permissions and engines has no "engines:" line.', permsLine);

    mismatch(`engines: HARNESS.md says ${doc.engines.ids.join(", ")}, harness.config.ts says ${h.engines.join(", ")}.`, doc.engines.line);
  }
  return out;
}

const SKIP_NOTE = /\b(?:never|don't|do not)\s+(?:call\s+)?`?save_note\b/i;

function pillarFindings(h: LoadedHarness, briefs: Map<string, string | null>, instructions: string, doc: HarnessDoc | null): Finding[] {
  const out: Finding[] = [];
  const texts = [...briefs.values()].filter((t): t is string => typeof t === "string");
  const choices = [instructions, ...texts].some((t) => t.includes("show_choices"));
  if (!choices && Object.keys(h.blocks).length === 0) {
    out.push(warning("pillar-decisions", "No brief or instruction asks for show_choices and the harness has no custom block: the person has nothing to decide with.", MANIFEST));
  }
  if (Object.keys(h.actions).length <= 1 && !h.path && !choices) {
    out.push(warning("pillar-flow", "One action, no path and no choices: this is effectively a chat. Add actions, a path, or choices that lead somewhere.", MANIFEST));
  }
  if (texts.length > 0 && texts.every((t) => SKIP_NOTE.test(t))) {
    out.push(warning("pillar-context", "Every brief tells the AI not to save a note: closed tasks keep nothing.", MANIFEST));
  }
  const context = doc?.sections.get("Context");
  if (doc && !sectionText(context)) out.push(warning("pillar-context", "HARNESS.md → Context is empty: say what each closed task must keep.", HARNESS_MD, context?.line));
  return out;
}

/** One line per finding, then the counts. */
export function formatFindings(findings: Finding[]): string {
  if (findings.length === 0) return "No problems found.\n";
  const lines = findings.map((f) => `${f.severity.padEnd(8)}${f.rule.padEnd(21)}${(f.line ? `${f.file}:${f.line}` : f.file).padEnd(22)}${f.message}`);
  const errors = findings.filter((f) => f.severity === "error").length;
  return `${lines.join("\n")}\n\n${plural(errors, "error")}, ${plural(findings.length - errors, "warning")}\n`;
}

export async function checkCommand(args: string[], io: Io): Promise<number> {
  const { values, positionals } = parseCommand(args, { json: { type: "boolean" }, harness: { type: "string" } });
  if (positionals.length > 0) throw new UsageError("Usage: humanharness check [--json] [--harness <dir>]");
  const { findings } = await checkHarness(path.resolve(io.cwd, values.harness ?? "."));
  io.stdout.write(values.json ? `${JSON.stringify(findings, null, 2)}\n` : formatFindings(findings));
  return findings.some((f) => f.severity === "error") ? 1 : 0;
}

import type { Writable } from "node:stream";
import { type ChoiceOption, choicesSchema } from "@humanharness/harness-sdk";
import { CORE_LOCALES } from "@humanharness/i18n";
import type { Event } from "@humanharness/runtime";

const DIM = "\x1b[2m";
const RESET = "\x1b[0m";

/** The app's own English message for an error code (`errors.*`), with the engine's name filled in. */
export function errorMessage(code: string, engine: string): string {
  const errors = CORE_LOCALES.en.errors as Record<string, unknown>;
  const text = errors[code];
  return (typeof text === "string" ? text : code).replaceAll("{{engine}}", engine);
}

/** `run`'s window: the events the app would show, as plain text. */
export class TerminalView {
  /** The options of the last `choices` block shown; `run` clears it before each operation. */
  choices: ChoiceOption[] = [];
  private lineStart = true;

  constructor(
    private readonly out: Writable,
    private readonly engineName: string,
    private readonly color = false,
  ) {}

  event(e: Event): void {
    if (e.type === "text") this.write(e.delta);
    else if (e.type === "paragraph") this.write("\n\n");
    else if (e.type === "activity" && e.state === "start") this.line(this.dim(`  · ${e.kind}: ${e.detail}`));
    else if (e.type === "block") this.block(e.name, e.data);
    else if (e.type === "done") {
      if (e.ok) this.newline();
      else this.line(`✗ ${errorMessage(e.error.code, this.engineName)}${e.error.detail ? ` (${e.error.detail})` : ""}`);
    }
  }

  private block(name: string, data: unknown): void {
    if (name === "save_note") return;
    if (name === "choices") {
      const parsed = choicesSchema.safeParse(data);
      if (!parsed.success) return;
      this.choices = parsed.data.options;
      this.newline();
      this.write("\n");
      parsed.data.options.forEach((o, i) => this.line(`  ${i + 1}. ${o.label}`));
      return;
    }
    this.line(`  [${name}]`);
    this.line(

        .split("\n")
        .map((l) => `    ${l}`)
        .join("\n"),

    return this.color ? `${DIM}${s}${RESET}` : s;
  }

  private newline(): void {
    if (!this.lineStart) this.write("\n");
  }

    this.newline();
    this.write(`${s}\n`);
  }

    if (!s) return;
    this.out.write(s);
    this.lineStart = s.endsWith("\n");

import type { ActionCost } from "@humanharness/harness-sdk";
import type { UsageMeta } from "@humanharness/shell/tasks";
import type { TurnUsage } from "@humanharness/ui/client";

export const REPORT_PHASES = ["run", "follow-up", "checkpoint", "close"] as const;
export type ReportPhase = (typeof REPORT_PHASES)[number];

export interface PhaseUsage {
  turns: number;
  input: number;
  output: number;
  cacheRead: number;
  cacheWrite: number;
}

/** What `run` prints at the end (spec §8). */
export interface RunReport {
  folder: string;
  action: string;
  /** The action's declared cost hint. */
  cost: ActionCost;
  tier?: string;
  /** Absent: the engine's default model. */
  model?: string;
  /** The model the engine said it ran. */
  reportedModel?: string;
  effort?: string;
  cap?: number;
  phases: Partial<Record<ReportPhase, PhaseUsage>>;
  /** The most context the task's session held after a turn. */
  peakContext?: number;
  notePath?: string;
}

/** Adds up the turns `run` records: the same TurnController calls the app's usage log gets. */
export class UsageTally {
  private readonly phases: Partial<Record<ReportPhase, PhaseUsage>> = {};
  private profile: Pick<RunReport, "tier" | "model" | "reportedModel" | "effort" | "cap"> = {};
  private peak: number | undefined;
  private task: string | undefined;
  private ranFirst = false;

  add(meta: UsageMeta, usage: TurnUsage | undefined, ok: boolean): void {
    if (meta.task !== this.task) {
      this.task = meta.task;
      this.ranFirst = false;
    }
    const phase: ReportPhase = meta.phase === "close" || meta.phase === "checkpoint" ? meta.phase : this.ranFirst ? "follow-up" : "run";
    if (phase === "run" && ok) this.ranFirst = true;
    if (meta.tier) {
      // The latest profile wins: after a fallback, it is the one that ran.
      this.profile = {
        tier: meta.tier,
        ...(meta.model ? { model: meta.model } : {}),
        ...(meta.effort ? { effort: meta.effort } : {}),
        ...(meta.cap ? { cap: meta.cap } : {}),
        ...(this.profile.reportedModel ? { reportedModel: this.profile.reportedModel } : {}),
      };
    }
    if (meta.reportedModel) this.profile.reportedModel = meta.reportedModel;
    const p = (this.phases[phase] ??= { turns: 0, input: 0, output: 0, cacheRead: 0, cacheWrite: 0 });
    p.turns++;
    p.input += usage?.inputTokens ?? 0;
    p.output += usage?.outputTokens ?? 0;
    p.cacheRead += usage?.cacheReadTokens ?? 0;
    p.cacheWrite += usage?.cacheWriteTokens ?? 0;
  }

  context(used: number): void {
    this.peak = Math.max(this.peak ?? 0, used);
  }

  report(base: Pick<RunReport, "folder" | "action" | "cost" | "notePath">): RunReport {
    return { ...base, ...this.profile, phases: this.phases, ...(this.peak !== undefined ? { peakContext: this.peak } : {}) };
  }
}

const n = (v: number) => v.toLocaleString("en-US");

/** Input and output over every phase; cache reads and writes are shown, not added. */
export function usedTokens(r: RunReport): number {
  return Object.values(r.phases).reduce((sum, p) => sum + p.input + p.output, 0);
}

export function formatReport(r: RunReport): string {
  const lines = [
    "",
    "Report",
    `  tier          ${r.tier ?? "–"}`,
    `  model         ${r.model ?? "engine default"}${r.reportedModel ? ` (engine reported: ${r.reportedModel})` : ""}`,
    `  effort        ${r.effort ?? "–"}`,
    `  cap           ${r.cap ? `${n(r.cap)} tokens` : "–"}`,
    "",
    `  ${"phase".padEnd(12)}${"turns".padStart(6)}${"input".padStart(10)}${"output".padStart(10)}${"cache read".padStart(12)}${"cache write".padStart(13)}`,
  ];
  for (const phase of REPORT_PHASES) {
    const p = r.phases[phase];
    if (!p) continue;
    lines.push(`  ${phase.padEnd(12)}${String(p.turns).padStart(6)}${n(p.input).padStart(10)}${n(p.output).padStart(10)}${n(p.cacheRead).padStart(12)}${n(p.cacheWrite).padStart(13)}`);
  }
  lines.push("");
  if (r.peakContext !== undefined) {
    lines.push(`  peak context  ${n(r.peakContext)}${r.cap ? ` of ${n(r.cap)} (${Math.round((r.peakContext / r.cap) * 100)}%)` : ""}`);
  }
  lines.push(`  verdict       used about ${n(usedTokens(r))} tokens; cost hint says ${r.cost}`);
  lines.push(`  usage log     ${path.join(r.folder, ".harness", "usage.jsonl")}`);
  if (r.notePath) lines.push(`  note          ${r.notePath}`);
  return `${lines.join("\n")}\n`;
}

  await fs.mkdir(folder, { recursive: true });

      harness,
      engine,
      folder,
      gitdir,
      language,
      command: command.command,
      env: command.env,
      references: references.map((r) => ({ label: r.label[language], path: r.path })),
      onSession: (s) => void tasks.sessionStarted(s).catch(() => undefined),

      await rt?.endSession();
    },
    saveHistory: async (message) => {
      const rt = await runtime.peek()?.catch(() => null);
      await rt?.history.save(message);

    await turns.flush();

  }
  const report = tally.report({ folder, action: o.action, cost: action.cost, ...(lastNote ? { notePath: lastNote } : {}) });
  out.write(formatReport(report));
  return report;

export async function runCommand(args: string[], io: Io): Promise<number> {
  const { values, positionals } = parseCommand(args, {
    engine: { type: "string" },
    tier: { type: "string" },
    folder: { type: "string" },
    language: { type: "string" },
    harness: { type: "string" },
  });
  if (positionals.length !== 1) throw new UsageError(RUN_USAGE);
  if (values.tier !== undefined && !(TIERS as readonly string[]).includes(values.tier)) throw new UsageError(`Unknown tier "${values.tier}": use light, standard or deep.`);
  if (values.language !== undefined && !(LANGUAGES as readonly string[]).includes(values.language)) throw new UsageError(`Unknown language "${values.language}": use es or en.`);
  const controller = new AbortController();
  const onInterrupt = () => controller.abort();
  process.once("SIGINT", onInterrupt);
  try {
    await runTask({

      ...(values.language ? { language: values.language as Language } : {}),
      input: io.stdin,
      output: io.stdout,
      signal: controller.signal,
    });
    return 0;
  } finally {
    process.off("SIGINT", onInterrupt);

import { type SpawnOptions, spawn } from "node:child_process";
import path from "node:path";
import type { Writable } from "node:stream";
import { availableEngines } from "@humanharness/engines";
import { checkHarness, formatFindings } from "./check";
import { type Io, UsageError, parseCommand } from "./cli";
import { shellDir } from "./paths";

/** The part of child_process.spawn `dev` uses (tests replace it). */
export type DevSpawn = (command: string, args: string[], options: SpawnOptions) => { on(event: "exit", listener: (code: number | null) => void): unknown; on(event: "error", listener: (err: Error) => void): unknown };

export interface DevOptions {
  harnessDir: string;
  /** Preselects this engine in a fresh app (HH_DEV_ENGINE). */
  engine?: string;
  /** Builds the app into this folder instead of opening it (HH_OUT_DIR; the end-to-end test). */
  build?: string;
  out: Writable;
  spawn?: DevSpawn;
}

/** `check`, then the shell's electron-vite with HH_HARNESS_DIR: the mechanism `corepack pnpm app:dev` uses for the demo. */
export async function devCommand(o: DevOptions): Promise<number> {
  const root = path.resolve(o.harnessDir);
  const { findings, harness } = await checkHarness(root);
  if (findings.length > 0) o.out.write(formatFindings(findings));
  if (!harness || findings.some((f) => f.severity === "error")) {
    o.out.write("Fix the errors above before opening the app.\n");
    return 1;
  }
  if (o.engine && !availableEngines(harness.engines, "development").some((e) => e.id === o.engine)) {
    throw new UsageError(`Engine "${o.engine}" is not available for ${harness.id}.`);
  }
  const shell = shellDir();
  const env: NodeJS.ProcessEnv = { ...process.env, HH_HARNESS_DIR: root };
  // Electron started as plain Node would not open a window.
  delete env.ELECTRON_RUN_AS_NODE;
  if (o.engine) env.HH_DEV_ENGINE = o.engine;
  if (o.build) env.HH_OUT_DIR = path.resolve(o.build);
  const child = (o.spawn ?? (spawn as unknown as DevSpawn))(path.join(shell, "node_modules", ".bin", "electron-vite"), [o.build ? "build" : "dev"], {
    cwd: shell,
    env,
    stdio: "inherit",
  });
  return new Promise((resolve) => {
    child.on("exit", (code) => resolve(code ?? 1));
    child.on("error", () => resolve(1));
  });
}

export async function devCommandLine(args: string[], io: Io): Promise<number> {
  const { values, positionals } = parseCommand(args, { engine: { type: "string" }, build: { type: "string" }, harness: { type: "string" } });
  if (positionals.length > 0) throw new UsageError("Usage: humanharness dev [--engine <id>] [--build <dir>] [--harness <dir>]");
  return devCommand({
    harnessDir: path.resolve(io.cwd, values.harness ?? "."),
    ...(values.engine ? { engine: values.engine } : {}),
    ...(values.build ? { build: path.resolve(io.cwd, values.build) } : {}),
    out: io.stdout,
  });
}

# Authoring a harness

A harness lives in its own repository and depends on `@humanharness/cli` only: until the core is published (plan 4b) that dependency is `link:<core>/packages/cli`. The CLI, `humanharness`, is in `packages/cli`.

## Commands

| Command | What it does |
|---|---|
| `init <dir> [--core <path>] [--id <id>]` | Copies `packages/cli/template/` (the id replaces `example-harness`), writes `package.json` with the `link:` dependency and the `check`, `run` and `dev` scripts, appends the first entry of `HARNESS.md`'s decision log, installs the guide, then runs `corepack pnpm install` and `git init` (`--skip-install` links the CLI directly instead; tests use it). |
| `check [--json]` | Loads the manifest with the SDK and reads `HARNESS.md` (`packages/cli/src/check.ts`). Errors exit with 1. |
| `run <action> …` | One task against a real engine, with the app's own `TaskManager` and `TurnController` (`packages/cli/src/run.ts`), the terminal as the window, and a usage report at the end. |
| `dev [--engine <id>] [--build <dir>]` | `check`, then the shell's `electron-vite dev` with `HH_HARNESS_DIR` (and `HH_DEV_ENGINE`; `--build` builds into `<dir>` through `HH_OUT_DIR`). |

`check`, `run` and `dev` work on the current folder, or on `--harness <dir>`. From the core repository: `corepack pnpm humanharness run manifest --harness harnesses/demo`.

## The template and what a harness imports

The template (`packages/cli/template/`) runs as is: one action (`example`, standard tier, light cost), one custom block (`example_card`), `ui/App.tsx`, strings in Spanish and English, and a `HARNESS.md` that already describes it, so `check` reports nothing. A harness imports `@humanharness/cli/sdk` (the SDK, `z` included: one zod for the manifest and the SDK) and `@humanharness/cli/ui` (the UI kit and `useTranslation`). The shell's renderer build dedupes React and i18n and may serve a harness folder outside the repository (`packages/shell/electron.vite.config.ts`).

## The guide

`packages/cli/guide/new-harness.md` is one engine-agnostic playbook: eight phases (task, decisions, flow, context, models, permissions and engines, identity, verify), one question at a time, each phase ending with its `HARNESS.md` section and the code updated together. `init` installs it unchanged as `.claude/skills/new-harness/SKILL.md` (Claude Code) and between markers in `AGENTS.md` (Codex) (`packages/cli/src/guide.ts`).

## HARNESS.md and check

`HARNESS.md` is the harness's living decision log: Task, Decisions, Flow, Context, Models, Permissions and engines, Identity, Open questions, Decision log. `check` reads two things from it (`packages/cli/src/harness-md.ts`): the Flow table (`| Action | Tier | Cost | Purpose |`, one row per action plus `(questions)`) and the permission lines (`- edit: none — reason`, `exec`, `web`, `engines: claude, codex`).

- Errors: `schema` (each zod issue), `i18n` (locale files, key parity, `t("key")` in `ui/`), `brief-missing`, `brand` (`brandNames()` in `packages/engines`), `engine-not-allowed` (excluded, unknown, or pending outside development), `harness-md-missing`, `harness-md-mismatch`.
- Warnings, one per pillar plus resources: `pillar-decisions`, `pillar-flow`, `pillar-context`, `tier-cost`, `permissions-wide`, `open-questions`.

## run's report

Per phase (`run`, `follow-up`, `checkpoint`, `close`): turns, input, output, cache read and cache write tokens; the tier, model (asked and reported), effort and cap; the peak context against the cap; and "used about N tokens" (input + output) next to the action's cost hint. The same lines go to `<folder>/.harness/usage.jsonl`, as in the app.

## Compliance

The CLI never reads `~/.claude`, `~/.codex` or `~/.gemini` and never handles credentials: `run` checks the engine only through its official CLI (`detectEngine`, as the app does) and stops with the app's own message when it isn't installed, current or signed in.
