## A3, A4: JSON compliance and latency

Ten prompts in one session, run from the userData folder with the full A1 argv (`--output-format json`): turn 1 with `--session-id 22222222-2222-4222-8222-222222222222`, turns 2–10 with `--resume` of the same id, each timed with `/usr/bin/time -p`. Per-turn prompt:

```
Review the prompt between the markers. Answer with the JSON object only.
<<<
{prompt}
>>>
```

- **A3 holds: 10/10** answers were a bare JSON object with a valid `verdict` (no prose, no code fence), measured with the per-turn line "Answer with the JSON object only". Spanish prompts got English issues (the brief is English).
- **A4: resumed turns (n = 9) p50 4.21 s; 8/9 under 5 s; max 65.94 s** (with n = 9 the true p90 is the outlier). Eight of nine finished under 5 s; turn 6 stalled for about a minute on the API side (`duration_api_ms` jumped by ~62 s; same answer size as its neighbours). The same ~66 s stall hit both A2 first-probe runs. So the 6 s default holds for the normal case, and the timeout-then-send-as-typed path is not theoretical: it will fire. Open question 1 stays as written (6 s, revisit with dogfooding numbers). Note that the wall time includes the CLI start (~1 s): a resumed turn is a new `claude -p` process.
- Every turn wrote cache: history grows ~300–500 tokens per turn (cache read 3.1k → 6.5k over ten turns). Turn 1 cached ~4.2k of prefix (system + brief).
- For Task 7: on `send` the model often repeats the whole prompt as `rewrite` (turn 9: 260 output tokens for a `send`). The brief should say "`rewrite` only with `suggest`", and `parseReview` should ignore a `rewrite` equal to the prompt.

## Decisions for the plan

- Task 6: keep `--tools ""` in the `noTools` branch (A1 holds), together with the `--disallowedTools` list and the strict empty MCP config (A7).
- Decision 1 confirmed: the Sidekick folder lives under `userData`, never under the base (A2).
- Task 7: keep the per-turn "Answer with the JSON object only" line, as tested (A3 10/10 was measured with it); still let `parseReview` tolerate stray text cheaply. Tell the model to omit `rewrite` on `send`.
- Default wait: keep 6 s (A4 p50 4.2 s; 8/9 under 5 s; max 66 s); expect occasional ~60 s API stalls to hit the timeout. Codex's cold first turn (~10 s) exceeds 6 s; warm turns are ~1.3 s.
- Task 8: Claude reports `usage` on the `result` line (A6); Codex reports `usage` events per turn (A5). Haiku's thinking tokens are inside `output_tokens`.
