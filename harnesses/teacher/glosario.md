# Teacher glossary

One name per thing in the teacher UI. Prose is English; the UI terms stay in Spanish, as the teacher sees them.
Decided in round 3, group 4 (H21, H42, H56), options page https://claude.ai/artifact/5PKKAhrn2FCUJKnDupwFND, canvas v52.

When a screen needs one of these ideas, use the term here. Do not invent a synonym.

## Class state

| Term | Means | Never |
|---|---|---|
| aprobada | The teacher marked the class as ready. Counts read "0 de 8 aprobadas". | revisada, lista |
| dada en el aula | The class was taught in the classroom. Tag "Dada en el aula"; counts read "4 de 8 ya dadas en el aula", "28 que diste en el aula". | dada (alone, as a tag) |

## Sources

| Term | Means | Never |
|---|---|---|
| Estilo de cita | The citation style (APA 7, MLA 9, Chicago, ISO 690), in Ajustes, Colegio nuevo and Editar materia. | Formato de citas, Estilo para exportar |
| Autores | The source's authors field, even with one author. | Autor |
| Editorial o revista | Who published the source. | Publicación |
| Tipo | Kind, then medium: "Artículo · web". | "Web · artículo", "Artículo de divulgación · web" |
| Edición, Volumen, Número, Páginas | Citation fields; shown only for the types that use them (H47, v58). | Ed., Vol., Nro., Pág. |
| Capítulo, Editores del libro | Fields of a book chapter, asked with "¿Es el libro entero o un capítulo?". | Sección, Compiladores |
| Manuales | School textbooks as a source group. | Libros de texto |
| Ver acá | Open the file inside the app. | Abrir |
| Guardar una copia | Save the original file to the computer. | Descargar el original |
| Usar \| No usar | Per-source choice in a new class; a segmented control, the chosen half filled. | an "Elegida" tag |

## Exams

| Term | Means | Never |
|---|---|---|
| Contenidos | What the exam covers. "4 contenidos". | Temas |
| Versión A / B | Each version has its own questions, with the same contents and the same difficulty. | "las mismas preguntas en otro orden" |
