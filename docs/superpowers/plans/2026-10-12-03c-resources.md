# Human Harness — Plan 3c: Resources (models and context)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every task runs on a model, an effort and a context cap chosen for it: the manifest gives each action (and free questions) an abstract tier (`light`, `standard`, `deep`), the user can change each task's tier or make it custom and change what each tier runs on per engine (Settings › Modelos), the profile is resolved once when the task starts and applied to every call of that task, an unavailable model falls back to the tier below, and a quiet checkpoint turn saves the decisions before the engine compacts, with a context meter on the task row.

**Architecture:** `harness-sdk` gets `TIERS` and the optional `tier` fields. `engines` gets the model vocabulary (`Effort`, `ModelSpec`, `ModelProfile`, `ModelsConfig`) and `DEFAULT_TIERS`. A pure shell module (`models.ts`) cleans `config.json` → `models`, resolves a task's `ModelProfile` and walks the fallback chain. The transports take the profile per turn: Claude appends `--model --effort --autocompact`; the ACP transport spawns the adapter with our own `CODEX_CONFIG` (a new process when the profile changes), saves the offered model list and checks `currentModelId`. The runtime emits two new events (`context`, `compaction`) and a new error code (`model-unavailable`). The `TaskManager` stores the profile with the task, retries a first turn on the fallback profile, tracks the context in use and runs the checkpoint turn. The UI gets a "Modelos" Settings tab, a context meter in the side panel, the checkpoint label and the fallback notice.

**Tech Stack:** unchanged from plan 3 (Electron 44, electron-vite 5, React 19, i18next 26, Vitest 5 + happy-dom, zod 4, Playwright 1.63.0). No new dependency; `@humanharness/ui` gains a type-only workspace dependency on `@humanharness/engines`.

Spec: `docs/superpowers/specs/2026-10-12-resources-models-context-design.md` (source of truth; section numbers below refer to it). Previous plan: `docs/superpowers/plans/2026-10-12-03-flow-and-context.md`. Mockups: canvas page "Plan 3c · Modelos".

## Decisions this plan takes where the spec leaves room

- **Error code spelling.** The spec writes `model_unavailable`; the existing codes are kebab-case (`engine-not-installed`, `out-of-quota`), so the code is **`model-unavailable`**.
- **Fallback chain.** "Retry once with the next tier down" is read as: each failed attempt is retried once on the next candidate of the chain (deep → standard → light → engine default), skipping candidates whose model already failed, until one works or the chain ends. A `custom` profile goes straight to the engine default. A profile without a model (engine default) has no fallback. Only a task's **first** turn falls back: later turns already proved the model works.
- **Codex "model not in the saved list"** is checked before the turn (`firstOffered`): the task starts on the first offered candidate, with the fallback notice, and no turn is wasted.
- **Fallback turns are invisible in the chat.** The first attempt is run with `holdModelError` (its `model-unavailable` end is neither logged nor shown) only when a fallback exists; the retry runs with `skipUserEntry` so the person's message is logged once. Without a fallback, the error card shows (`errors.model-unavailable`).
- **A custom setting for another engine** (the user changed engines after setting it) is ignored by the resolution, which then uses the manifest tier.
- **Context in use (Claude).** The last top-level `assistant` message's `usage` (input + cache read + cache creation) is the size of the last call, so it wins; the `result` usage is the fallback when no assistant usage was seen.
- **Engine-reported model.** The `usage` event gains an optional `model` (Claude: `system/init` `model`; Codex: `currentModelId` without `[effort]`), logged as `reportedModel`, so the real run (Task 18) can assert what actually ran.
- **Checkpoint notes** use the task's own note slug, so the closing turn overwrites them. A checkpoint note does not skip the closing turn (`noteSaved` stays false; `checkpointNote` is set); a closing turn that brings no note still ends the topic `done` when a checkpoint note exists.
- **Checkpoint placement.** It runs before the next **follow-up** turn of the waiting task (typed, or a follow-up pick). A pick that closes the task does not run it: the closing turn saves the note anyway.
- **Usage log.** Records keep `phase` and add `kind: "checkpoint" | "compaction"`; checkpoint turns are `phase: "checkpoint"` + `kind: "checkpoint"`; a detected compaction appends a usage-less `kind: "compaction"` line. `summarizeUsage` ignores both kinds.
- **Saving `models`.** `hh:saveConfig` accepts any object under `models` and stores its cleaned form (a bad entry is dropped, never rejected); a non-object is `invalid`. Reading cleans again.
- **No new IPC channel.** The Settings tab reads `AppState.models` (a `ModelsView`) and saves through `saveConfig({ models })`.

```ts
import type { Tier } from "@humanharness/harness-sdk";

/** Reasoning effort as both engines name it (Claude `--effort`, Codex `model_reasoning_effort`). */
export const EFFORTS = ["low", "medium", "high", "xhigh", "max"] as const;
export type Effort = (typeof EFFORTS)[number];

/** What a tier (or a custom task) runs on. `model` absent: the engine's own default model. */
export interface ModelSpec {
  model?: string;
  effort: Effort;
  /** Context cap in tokens: the engine compacts when it reaches it. */
  cap: number;
}

/** The model a task runs on: resolved once when the task starts and kept with it (spec §5). */
export interface ModelProfile extends ModelSpec {
  engine: string;
  tier: Tier | "custom";
  /** After a fallback: the model the plan didn't include. */
  fallbackFrom?: string;
}

/** A task the user set to custom in Settings › Modelos. */
export interface CustomModel extends ModelSpec {
  engine: string;
}

/** A task's setting: a tier, or its own model. */
export type TaskModelChoice = Tier | { custom: CustomModel };

/** `config.json` → `models` (per app, so per harness). Always read through the shell's `cleanModels`. */
export interface ModelsConfig {
  /** By action id, or "questions" for free questions. */
  tasks?: Record<string, TaskModelChoice>;
  /** By engine id, then tier: overrides of DEFAULT_TIERS. */
  tiers?: Record<string, Partial<Record<Tier, ModelSpec>>>;
}

/** A model an engine offers (Codex: from `session/new` `configOptions`). */
export interface ModelChoice {
  id: string;
  name?: string;
  description?: string;
}

/** What an engine offers in Settings: a fixed model list (Claude's aliases) and its efforts. */
export interface EngineModels {
  /** Fixed model ids; absent when the list comes from the engine itself (Codex, saved in engines.json). */
  list?: readonly string[];
  efforts: readonly Effort[];
}

export const MIN_CAP = 100_000;
export const MAX_CAP = 1_000_000;
/** The context caps Settings offers (spec §5.1). */
export const CAP_OPTIONS = [100_000, 200_000, 400_000, 1_000_000] as const;
/** Claude's aliases always point at the latest model of each family. */
export const CLAUDE_MODELS = ["haiku", "sonnet", "opus"] as const;

/** A model id safe to put on a command line or in CODEX_CONFIG: never a flag. */
const MODEL_ID = /^[A-Za-z0-9._\[\]-]{1,64}$/;

export function isModelId(v: unknown): v is string {
  return typeof v === "string" && MODEL_ID.test(v) && !v.startsWith("-");
}

export function isEffort(v: unknown): v is Effort {
  return typeof v === "string" && (EFFORTS as readonly string[]).includes(v);
}

export function isCap(v: unknown): v is number {
  return typeof v === "number" && Number.isInteger(v) && v >= MIN_CAP && v <= MAX_CAP;
}

/** The engine's default model at each tier: only the effort and the cap change. */
const ENGINE_DEFAULT: Readonly<Record<Tier, ModelSpec>> = {
  light: { effort: "low", cap: 100_000 },
  standard: { effort: "medium", cap: 200_000 },
  deep: { effort: "high", cap: 400_000 },
};

/** The core's tables (spec §5.1). Codex leaves `model` out so the defaults follow the engine's own. */
export const DEFAULT_TIERS: Readonly<Record<string, Readonly<Record<Tier, ModelSpec>>>> = {
  claude: {
    light: { model: "haiku", effort: "low", cap: 100_000 },
    standard: { model: "sonnet", effort: "medium", cap: 200_000 },
    deep: { model: "opus", effort: "high", cap: 400_000 },
  },
  codex: ENGINE_DEFAULT,
};

/** The core's spec for `tier` on `engine`; an engine without a table runs on its default model. */
export function defaultTier(engine: string, tier: Tier): ModelSpec {
  return { ...(DEFAULT_TIERS[engine] ?? ENGINE_DEFAULT)[tier] };
}
```

```ts
import { TIERS, type Tier } from "@humanharness/harness-sdk";
import {
  type Effort,
  type EngineDef,
  type ModelChoice,
  type ModelProfile,
  type ModelSpec,
  type ModelsConfig,
  type TaskModelChoice,
  defaultTier,
  isCap,
  isEffort,
  isModelId,
} from "@humanharness/engines";

/** The key free questions' setting lives under. */
export const QUESTIONS = "questions";
/** Action ids and engine ids, as the manifest and the registry spell them. */
const KEY = /^[a-z][a-z0-9_-]{0,63}$/;

const isObject = (v: unknown): v is Record<string, unknown> => typeof v === "object" && v !== null && !Array.isArray(v);
const isTier = (v: unknown): v is Tier => typeof v === "string" && (TIERS as readonly string[]).includes(v);

/** The key a task's setting lives under: its action, or "questions". */
export const taskKey = (action: string | undefined): string => action ?? QUESTIONS;

/** A model, effort and cap, each checked; null when any is wrong. */
export function cleanSpec(raw: unknown): ModelSpec | null {
  if (!isObject(raw) || !isEffort(raw.effort) || !isCap(raw.cap)) return null;
  if (raw.model !== undefined && !isModelId(raw.model)) return null;
  return { ...(raw.model !== undefined ? { model: raw.model } : {}), effort: raw.effort, cap: raw.cap };
}

function cleanChoice(raw: unknown): TaskModelChoice | null {
  if (isTier(raw)) return raw;
  if (!isObject(raw) || !isObject(raw.custom)) return null;
  const spec = cleanSpec(raw.custom);
  const engine = raw.custom.engine;
  return spec && typeof engine === "string" && KEY.test(engine) ? { custom: { engine, ...spec } } : null;
}

/**
 * `config.json` → `models`, cleaned field by field (spec §7): a bad entry is dropped, so the default
 * applies. Nothing from the file reaches the engine unchecked.
 */
export function cleanModels(raw: unknown): ModelsConfig {
  if (!isObject(raw)) return {};
  const tasks: Record<string, TaskModelChoice> = {};
  if (isObject(raw.tasks)) {
    for (const [key, value] of Object.entries(raw.tasks)) {
      const choice = KEY.test(key) ? cleanChoice(value) : null;
      if (choice) tasks[key] = choice;
    }
  }
  const tiers: NonNullable<ModelsConfig["tiers"]> = {};
  if (isObject(raw.tiers)) {
    for (const [engine, table] of Object.entries(raw.tiers)) {
      if (!KEY.test(engine) || !isObject(table)) continue;
      const clean: Partial<Record<Tier, ModelSpec>> = {};
      for (const tier of TIERS) {
        const spec = cleanSpec(table[tier]);
        if (spec) clean[tier] = spec;
      }
      if (Object.keys(clean).length > 0) tiers[engine] = clean;
    }
  }
  return { ...(Object.keys(tasks).length > 0 ? { tasks } : {}), ...(Object.keys(tiers).length > 0 ? { tiers } : {}) };
}

/** A profile stored in tasks.json, checked again before it can reach the engine. */
export function cleanProfile(raw: unknown): ModelProfile | null {
  if (!isObject(raw)) return null;
  const spec = cleanSpec(raw);
  const { engine, tier } = raw;
  if (!spec || typeof engine !== "string" || !KEY.test(engine) || !(isTier(tier) || tier === "custom")) return null;
  return { engine, tier, ...spec, ...(isModelId(raw.fallbackFrom) ? { fallbackFrom: raw.fallbackFrom } : {}) };
}

/** What `tier` runs on for `engine`: the user's table, else the core's. */
export function tierSpec(engine: string, tier: Tier, models: ModelsConfig): ModelSpec {
  return { ...(models.tiers?.[engine]?.[tier] ?? defaultTier(engine, tier)) };
}

/**
 * The task's profile (spec §5): the user's custom setting for this engine, else the user's tier for the
 * task, else the manifest's, else "standard", through the user's table, else the core's.
 */
export function resolveProfile(o: { engine: string; action?: string; manifestTier?: Tier; models: ModelsConfig }): ModelProfile {
  const choice = o.models.tasks?.[taskKey(o.action)];
  if (typeof choice === "object" && choice.custom.engine === o.engine) {
    const { engine: _engine, ...spec } = choice.custom;
    return { engine: o.engine, tier: "custom", ...spec };
  }
  const tier: Tier = typeof choice === "string" ? choice : (o.manifestTier ?? "standard");
  return { engine: o.engine, tier, ...tierSpec(o.engine, tier, o.models) };
}

/**
 * The profile to retry with when the plan doesn't include `p.model` (spec §5.3): the next tier down whose
 * model hasn't failed (deep → standard → light), then the engine's default model with the same effort and
 * cap. A custom profile goes straight to the engine default. Null when `p` already runs on the default.
 */
export function nextFallback(p: ModelProfile, models: ModelsConfig, tried: readonly string[] = []): ModelProfile | null {
  if (p.model === undefined) return null;
  const from = p.fallbackFrom ?? p.model;
  const failed = new Set([...tried, p.model]);
  const below = p.tier === "custom" ? [] : TIERS.slice(0, TIERS.indexOf(p.tier)).reverse();
  for (const tier of below) {
    const spec = tierSpec(p.engine, tier, models);
    if (spec.model === undefined || !failed.has(spec.model)) return { engine: p.engine, tier, ...spec, fallbackFrom: from };
  }
  const { model: _model, fallbackFrom: _from, ...rest } = p;
  return { ...rest, fallbackFrom: from };
}

/** Whether the engine's saved list (Codex) includes the profile's model; an unknown list includes everything. */
export function offered(p: ModelProfile, list: readonly ModelChoice[] | undefined): boolean {
  return p.model === undefined || !list?.length || list.some((m) => m.id === p.model);
}

/** `p`, or the first fallback the engine's saved list includes (checked before the turn, spec §5.3). */
export function firstOffered(p: ModelProfile, models: ModelsConfig, list: readonly ModelChoice[] | undefined): ModelProfile {
  let current: ModelProfile | null = p;
  const tried: string[] = [];
  while (current && !offered(current, list)) {
    if (current.model) tried.push(current.model);
    current = nextFallback(current, models, tried);
  }
  return current ?? p;
}

/** What Settings offers for an engine: its fixed list, or the one saved from the engine (engines.json). */
export function engineOffer(engine: EngineDef, saved: { models?: ModelChoice[]; efforts?: Effort[] }): { models: ModelChoice[]; efforts: Effort[] } {
  const fixed = engine.models?.list;
  return {
    models: fixed ? fixed.map((id) => ({ id })) : [...(saved.models ?? [])],
    efforts: saved.efforts?.length && !fixed ? [...saved.efforts] : [...(engine.models?.efforts ?? ["low", "medium", "high"])],
  };
}
```

```ts
/**
 * The adapter's `CODEX_CONFIG` for a task's profile (resources spec §5.2): only these keys are ever
 * written; `model` is left out for the engine's default model. Checked again here before it is used.
 */
export function codexConfig(profile: ModelProfile): string {
  if (profile.model !== undefined && !isModelId(profile.model)) {
    throw new Error(`Refusing a model id that reads as a flag: ${JSON.stringify(profile.model)}`);
  }
  if (!isEffort(profile.effort)) throw new Error(`Unknown effort: ${JSON.stringify(profile.effort)}`);
  if (!isCap(profile.cap)) throw new Error(`Context cap out of range: ${JSON.stringify(profile.cap)}`);
  return JSON.stringify({
    ...(profile.model !== undefined ? { model: profile.model } : {}),
    model_reasoning_effort: profile.effort,
    model_auto_compact_token_limit: profile.cap,
  });
}

type SelectOption = { value?: unknown; name?: unknown; description?: unknown };

/** The options of an ACP select config option, flat or grouped. */
function selectOptions(configOptions: unknown[], id: string): SelectOption[] | null {
  const option = configOptions.find((o): o is Record<string, unknown> => typeof o === "object" && o !== null && (o as { id?: unknown }).id === id);
  if (!option || option.type !== "select" || !Array.isArray(option.options)) return null;
  return (option.options as unknown[]).flatMap((o) => {
    if (typeof o !== "object" || o === null) return [];
    const group = o as { options?: unknown };
    return Array.isArray(group.options) ? (group.options as SelectOption[]) : [o as SelectOption];
  });
}

/**
 * The models and efforts an ACP agent offers, from session/new `configOptions` (Codex: the selects
 * "model" and "reasoning_effort"). Unsafe ids and unknown efforts are dropped. Null without models.
 */
export function offeredModels(configOptions: unknown): { models: ModelChoice[]; efforts: Effort[] } | null {
  if (!Array.isArray(configOptions)) return null;
  const models = (selectOptions(configOptions, "model") ?? [])
    .filter((o): o is SelectOption & { value: string } => isModelId(o.value))
    .slice(0, 50)
    .map((o) => ({
      id: o.value,
      ...(typeof o.name === "string" && o.name ? { name: o.name.slice(0, 80) } : {}),
      ...(typeof o.description === "string" && o.description ? { description: o.description.slice(0, 200) } : {}),
    }));
  if (models.length === 0) return null;
  const efforts = (selectOptions(configOptions, "reasoning_effort") ?? []).map((o) => o.value).filter(isEffort);
  return { models, efforts };
}
```

```ts
    try {
      done = await this.runTurn(c, CHECKPOINT_PROMPT, { ...(c.action ? { action: c.action } : {}), phase: "checkpoint", quiet: true });
    } catch (err) {
      if (err instanceof TurnNotStarted) await this.setStatus(c.id, "waiting");
      throw unwrap(err);
    }
    if ((!done.ok && done.error.code === "cancelled") || this.cancelRequested) {
      await this.setStatus(c.id, "waiting");
      return false;
    }
    // Any other failure doesn't stop the person's turn: the engine still compacts on its own.
    return true;
  }

  /**
   * Keeps the context in use after a turn. A compaction (reported, or `used` falling by more than half)
   * allows a new checkpoint and is logged (spec §6).
   */
  private async track(id: string, seen: { used?: number; size?: number; compacted?: boolean }): Promise<void> {
    const before = (await this.d.store.load()).current;
    if (before?.id !== id) return;
    const prev = before.context?.used;
    const compacted = seen.compacted === true || (prev !== undefined && seen.used !== undefined && seen.used < prev * COMPACTED_DROP);
    const context = seen.used !== undefined ? { used: seen.used, ...(seen.size !== undefined ? { size: seen.size } : {}) } : undefined;
    await this.update((s) =>
      s.current?.id === id ? { ...s, current: { ...s.current, ...(context ? { context } : {}), ...(compacted ? { checkpointed: false } : {}) } } : s,
    );
    if (!compacted) return;
    try {
      await this.d.recordCompaction?.(before);
    } catch (err) {
      console.error("Could not record the compaction", err);
    }
  }
```

```ts
export function profileMeta(p: ModelProfile): Pick<UsageMeta, "tier" | "model" | "effort" | "cap"> {
  return { tier: p.tier, ...(p.model !== undefined ? { model: p.model } : {}), effort: p.effort, cap: p.cap };
}

function metaFields(meta: UsageMeta): Partial<UsageRecord> {
  return {
    ...(meta.action ? { action: meta.action } : {}),
    ...(meta.task ? { task: meta.task } : {}),
    ...(meta.phase ? { phase: meta.phase } : {}),
    ...(meta.phase === "checkpoint" ? { kind: "checkpoint" as const } : {}),
    ...(meta.tier ? { tier: meta.tier } : {}),
    ...(meta.model ? { model: meta.model } : {}),
    ...(meta.effort ? { effort: meta.effort } : {}),
    ...(meta.cap ? { cap: meta.cap } : {}),
    ...(meta.reportedModel ? { reportedModel: meta.reportedModel } : {}),
  };
}

/** The usage record for a finished turn, or null when the engine reported nothing. */
export function usageRecord(entry: ChatEntry, engine: string, meta: UsageMeta = {}, firstLimits?: LimitWindow[]): UsageRecord | null {
  if (!entry.usage && !entry.limits) return null;
  return {
    at: entry.at,
    engine,
    ...metaFields(meta),
    ok: !entry.error,
    ...(entry.usage ? { usage: entry.usage } : {}),
    ...(entry.limits ? { limits: entry.limits } : {}),
    ...(firstLimits ? { firstLimits } : {}),
  };
}

/** A line for a compaction the task manager detected (spec §8). */
export function compactionRecord(engine: string, meta: UsageMeta, at: string = new Date().toISOString()): UsageRecord {
  return { at, engine, ...metaFields(meta), kind: "compaction", ok: true };
}
```

```tsx
import { useId, useState } from "react";
import { useTranslation } from "react-i18next";
import type { Language, Tier } from "@humanharness/harness-sdk";
import type { Effort, ModelSpec, ModelsConfig, TaskModelChoice } from "@humanharness/engines";
import { Segmented } from "./chrome";
import type { AppState, HarnessClient, ModelsView } from "./client";
import { uiLanguage } from "./FolderStep";

// Local copies: the UI only imports types from the core packages.
const TIERS: readonly Tier[] = ["light", "standard", "deep"];
const CAPS: readonly number[] = [100_000, 200_000, 400_000, 1_000_000];
const QUESTIONS = "questions";
const FALLBACK_SPEC: ModelSpec = { effort: "medium", cap: 200_000 };

type Choice = Tier | "custom";
type Offer = ModelsView["offered"][string];
const NO_OFFER: Offer = { models: [], efforts: ["low", "medium", "high"] };

/** 100000 → "100 k", 1000000 → "1 M". */
export function formatCap(n: number): string {
  return n >= 1_000_000 ? `${n / 1_000_000} M` : `${Math.round(n / 1000)} k`;
}

/** `models` with one task's setting replaced (null: back to the recommendation); empty sections go away. */
function withTask(models: ModelsConfig, key: string, choice: TaskModelChoice | null): ModelsConfig {
  const { tasks: old, ...rest } = models;
  const tasks = { ...old };
  if (choice === null) delete tasks[key];
  else tasks[key] = choice;
  return Object.keys(tasks).length > 0 ? { ...rest, tasks } : rest;
}

const withModel = (spec: ModelSpec, model: string | undefined): ModelSpec => {
  const { model: _old, ...rest } = spec;
  return model ? { ...rest, model } : rest;
};

/** The actions in path order, then the others, then free questions. */
function taskRows(state: AppState, lang: Language, questions: string): { key: string; label: string }[] {
  const path = (state.path ?? []).filter((id) => state.actions[id]);
  const ids = [...path, ...Object.keys(state.actions).filter((id) => !path.includes(id))];
  return [...ids.map((id) => ({ key: id, label: state.actions[id].label[lang] })), { key: QUESTIONS, label: questions }];
}

/**
 * Settings › Modelos (resources spec §7): how much model each task uses and what each level runs on, per
 * engine. Saved in config.json; a change applies to the next task, never to the running one.
 */
export function ModelsTab({ client, state, onChange }: { client: HarnessClient; state: AppState; onChange: (s: AppState) => void }) {
  const { t, i18n } = useTranslation();
  const tasksId = useId();
  const view = state.models;
  if (!view) return null;
  const lang = uiLanguage(state, i18n.language);
  const engine = state.config.engineId ?? state.engines[0]?.id ?? "";
  const models: ModelsConfig = state.config.models ?? {};
  const save = (next: ModelsConfig) => void client.saveConfig({ models: next }).then(onChange, () => {});
  const tierSpec = (tier: Tier): ModelSpec => models.tiers?.[engine]?.[tier] ?? view.defaults[engine]?.[tier] ?? FALLBACK_SPEC;
  const offer = view.offered[engine] ?? NO_OFFER;
  const rows = taskRows(state, lang, t("models.questions"));

  return (
    <div className="hh-tab">
      <section aria-labelledby={tasksId}>
        <h3 id={tasksId}>{t("models.tasks")}</h3>
        <p className="hh-caption">{t("models.tasksIntro")}</p>
        <div className="hh-rows">
          {rows.map(({ key, label }) => {
            const choice = models.tasks?.[key];
            const recommended = view.recommended[key] ?? "standard";
            const custom = typeof choice === "object" ? choice.custom : undefined;
            const spec = custom ?? tierSpec(typeof choice === "string" ? choice : recommended);
            return (
              <TaskRow
                key={key}
                label={label}
                recommended={recommended}
                choice={choice}
                spec={spec}
                offer={offer}
                onPick={(v) => save(withTask(models, key, v === "custom" ? { custom: { engine, ...spec } } : v === recommended ? null : v))}
                onCustom={(next) => save(withTask(models, key, { custom: { engine, ...next } }))}
                onRestore={() => save(withTask(models, key, null))}
              />
            );
          })}
        </div>
      </section>
    </div>
  );
}

function TaskRow({
  label,
  recommended,
  choice,
  spec,
  offer,
  onPick,
  onCustom,
  onRestore,
}: {
  label: string;
  recommended: Tier;
  choice: TaskModelChoice | undefined;
  /** The task's custom setting, or the level's settings a new custom one starts from. */
  spec: ModelSpec;
  offer: Offer;
  onPick: (choice: Choice) => void;
  onCustom: (spec: ModelSpec) => void;
  onRestore: () => void;
}) {
  const { t } = useTranslation();
  const editorId = useId();
  const [open, setOpen] = useState(false);
  const value: Choice = choice === undefined ? recommended : typeof choice === "string" ? choice : "custom";
  const options = (["light", "standard", "deep", "custom"] as const).map((v) => ({ value: v as Choice, label: t(`models.tier.${v}`) }));
  return (
    <div className="hh-row hh-model-task">
      <span className="hh-row-label">{label}</span>
      <Segmented
        label={label}
        value={value}
        options={options}
        onChange={(v) => {
          setOpen(v === "custom");
          onPick(v);
        }}
      />
      {value === "custom" && (
        <p className="hh-caption">
          {t("models.customSummary", { model: spec.model ?? t("models.engineDefault"), effort: t(`models.effortLevel.${spec.effort}`), cap: formatCap(spec.cap) })}{" "}
          <button type="button" aria-expanded={open} aria-controls={editorId} onClick={() => setOpen(!open)}>
            {t("models.edit")}
          </button>
        </p>
      )}
      {value !== "custom" && value !== recommended && (
        <p className="hh-caption">
          {t("models.changed", { tier: t(`models.tier.${recommended}`) })}{" "}
          <button type="button" onClick={onRestore}>
            {t("models.restore")}
          </button>
        </p>
      )}
      {value === "custom" && open && (
        <div id={editorId} className="hh-model-editor">
          <SpecFields spec={spec} offer={offer} onChange={onCustom} />
          <button
            type="button"
            onClick={() => {
              setOpen(false);
              onRestore();
            }}
          >
            {t("models.backToRecommended")}
          </button>
        </div>
      )}
    </div>
  );
}

/** Model, effort and context cap. A saved value the engine no longer lists stays selectable as it is. */
export function SpecFields({ spec, offer, onChange }: { spec: ModelSpec; offer: Offer; onChange: (s: ModelSpec) => void }) {
  const { t } = useTranslation();
  const id = useId();
  const models = spec.model === undefined || offer.models.some((m) => m.id === spec.model) ? offer.models : [{ id: spec.model }, ...offer.models];
  const efforts: Effort[] = offer.efforts.includes(spec.effort) ? offer.efforts : [...offer.efforts, spec.effort];
  const caps = CAPS.includes(spec.cap) ? CAPS : [...CAPS, spec.cap].sort((a, b) => a - b);
  return (
    <div className="hh-model-fields">
      <label htmlFor={`${id}-model`}>{t("models.model")}</label>
      <select id={`${id}-model`} value={spec.model ?? ""} onChange={(e) => onChange(withModel(spec, e.target.value || undefined))}>
        <option value="">{t("models.engineDefault")}</option>
        {models.map((m) => (
          <option key={m.id} value={m.id} title={m.description}>
            {m.name ?? m.id}
          </option>
        ))}
      </select>
      <label htmlFor={`${id}-effort`}>{t("models.effort")}</label>
      <select id={`${id}-effort`} value={spec.effort} onChange={(e) => onChange({ ...spec, effort: e.target.value as Effort })}>
        {efforts.map((e) => (
          <option key={e} value={e}>
            {t(`models.effortLevel.${e}`)}
          </option>
        ))}
      </select>
      <label htmlFor={`${id}-cap`}>{t("models.cap")}</label>
      <select id={`${id}-cap`} value={String(spec.cap)} onChange={(e) => onChange({ ...spec, cap: Number(e.target.value) })}>
        {caps.map((c) => (
          <option key={c} value={c}>
            {formatCap(c)}
          </option>
        ))}
      </select>
    </div>
  );
}
```

```ts
/** `models` with one level of one engine replaced; `tier` null clears the engine's whole table. */
function withTier(models: ModelsConfig, engine: string, tier: Tier | null, spec?: ModelSpec): ModelsConfig {
  const { tiers: old, ...rest } = models;
  const tiers = { ...old };
  if (tier === null || !spec) delete tiers[engine];
  else tiers[engine] = { ...tiers[engine], [tier]: spec };
  return Object.keys(tiers).length > 0 ? { ...rest, tiers } : rest;
}
```

```md
## Models and context caps

- Each task runs at a level: `light`, `standard` or `deep`. The manifest recommends one per action (`tier`) and for free questions (`questions.tier`); the person can change each task's level, or make it custom, in Settings › Modelos (`config.json` → `models`).

## Checkpoints

- After each turn the task keeps the context in use (`context` events: Claude's last call, Codex's `usage_update`).

## Measuring

`.harness/usage.jsonl` records each turn's tokens with its `task`, `phase` (`run`, `close`, `checkpoint`), level, model, effort and cap, and the model the engine said it ran. Compactions are lines of `kind: "compaction"`.
```
