# Student harness · teacher findings applied

Findings from the teacher user-testing rounds (`harnesses/teacher/hallazgos.md`, `decisions.md`) that
also hold for the student canvas (`core-v1` page, boards `K-*`). Not yet tested with student personas:
these are applied by analogy and must be checked in a first student round. UI copy stays in Spanish.

## Applied

| Teacher | Rule | Where in student |
|---|---|---|
| H01 | An action confirms where its result lives (tag, in-place change, Deshacer) | FinSesion "Guardado en Fracciones"; MapaInicial "Sacado · Deshacer" |
| H08 | One fact sheet for all sample data | Fractions topic: 6 concepts, 1 mastered, 1 to review; Inicio, Tema, FinSesion agree |
| H14 | Create button opens the form; everything can also be asked in the chat | NuevoTema: "También podés contarlo en una frase" |
| H17 | A scan shows it is being read, how long, that you can keep going | NuevoTema: "Leyendo el texto · 62% · falta 1 min" |
| H20 | Secondary text 14 px; selected segment filled amber, weight 600 | gen.cjs segmented control and concept evidence line |
| H22 | The chat says what it uses | Composer chip "Usa: tu cuaderno, 2 fotos"; strict-mode hint names the 2 photos |
| H23 | First run asks "¿Por dónde empezás?" with cards | New board InicioVacio |
| H25 / H53 | A change says it is shown first; saving says it notifies nobody | Cierre: "Si querés, te muestro cómo quedaría…", "No se manda a nadie" |
| H27 / H36 | AI-filled values say where they come from | MapaInicial: "Sale de: tu cuaderno, foto N", "Lo sumé yo: …" |
| H02 / H40 | Offline state: what was saved and how to go on | New board SinConexion |
| H13 | Search is a window over the screen, grouped | New board Busqueda (concepts, summaries, flashcards, material) |
